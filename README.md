# microsocks-static
Builds a static, musl-linked build of [microsocks](https://github.com/rofl0r/microsocks) at [`307950c`](https://github.com/rofl0r/microsocks/commit/307950cb1296b521fe86384fd695062ade5304b5).

The [Dockerfile](./Dockerfile) builds an image that has the binary at `/app/microsocks`.
